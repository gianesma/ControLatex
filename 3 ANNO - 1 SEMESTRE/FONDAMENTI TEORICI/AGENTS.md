# AGENTS.md - Repository ControLatex

## Panoramica del progetto
Repository per la gestione e la stesura di appunti universitari/di studio in LaTeX.

## Regole principali di scrittura LaTeX
Quando scrivi o modifichi file `.tex`, segui rigorosamente queste indicazioni:

- **Riferimento estetico e semantico:** Ispirati ai file sorgente `.tex` esistenti e alla struttura visiva del documento finale `main.pdf`.
- **Stile espositivo:** Prediligi un linguaggio chiaro e discorsivo, pensato per facilitare la comprensione di argomenti complessi.
- **Gerarchia delle sezioni:** Non utilizzare mai il comando `\paragraph{}`.
- **Formule matematiche:** Non inserire mai il punto fermo (`.`) alla fine delle formule matematiche (né in riga né in display).
- **Evidenziazione:** Non utilizzare mai il comando `\boxed{}`.

## Note operative per l'agente
- Prima di proporre modifiche strutturali, controlla il preambolo e le macro già definite nei file `.tex` principali per mantenere coerenza con `main.pdf`.
